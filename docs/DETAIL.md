# 书签（Bookmarks）

把一段回复钉在右侧栏里慢慢看，再就其中看不懂的地方回到主聊天提问。

## 用起来是这样的

1. **存进来**。每条已经结束的助手回复下面有两个图标动作，入口就是这两个：
   - **☆ 星标——「收藏到书签」**。只收藏，右侧栏保持原样，不会展开。收藏之后星标变成实心 ★；再点一次就是取消收藏：这条消息对应的收藏全部删掉，星标退回 ☆，聊天右侧「轮次导航」上这一轮的横线恢复普通样式（那一轮若还有别的收藏，横线仍在），右栏同样不会打开。
   - **→ 箭头——「收藏并展开书签」**。收藏并展开右栏到「书签」标签页。已经收藏过的那条再点箭头，只负责展开，并提示这条回复已经收藏过了。
   - 也可以点会话标题右侧工具区的**书签图标**打开右栏，用面板底部的「+ 粘贴一段文字」把任意一段文字存进去。
2. **慢慢看**。右栏里显示的是**渲染之后的 Markdown**：标题、段落、列表（含一层嵌套）、引用、表格、分隔线、围栏代码块、粗体/斜体/删除线/行内代码/链接都按聊天区那样排版，围栏代码按语言着色（没认出来的语言保持等宽纯文本）。卡片默认**整篇展开**，觉得太长可以点「收起」压成 120 像素高的滚动预览。
   - 卡片顶部左侧是来源标签（「回复」/「摘录」）和标题，右侧是时间：今天只显示 `HH:mm`，隔天显示 `MM-DD HH:mm`，跨年再补上年份。回复显示的是这条消息写下的时间，摘录显示的是存入的时间。
   - 来自回复的卡片左下角有「跳转」，点一下主对话会滚动到这条消息所在的位置；如果这一行还没被加载，它会沿着「加载更早」一页页往上翻（每页间隔约 240 毫秒）直到找到。结局有三种，提示各不相同：找到了（滚过去并居中）；真的翻到了会话开头（「加载更早」按钮已不存在或已置灰）仍然没有，才说「翻到会话开头也没有找到」；而超时（15 秒）、翻满页数上限（60 页）或连续 8 次拉页后会话不再变多，只说明「已尝试向上翻 N 页」，不声称到了开头。摘录卡片没有「跳转」。
3. **选中即问**。在卡片里拖选一段文字（至少两个字符），松开鼠标、或键盘选完之后，选区旁边才会浮出一个「→ 添加到主聊天」的胶囊按钮（配色沿用聊天区浮动按钮的主题令牌）。点它，这段文字交给聊天自己的「插入引用」动作，进入主聊天输入框，你补上自己的问题发送即可；在别处按下鼠标或清掉选区，按钮就消失。
   - 想引用整条而不选文字时，用卡片左下角的「提问」。

## 它做什么、不做什么

- 内容保存在浏览器本地（按会话分开，键为 `dsh-pin-bookmarks:v1:<会话号>`），刷新页面不会丢；清除站点数据会清掉。**收藏横线的外观是唯一的例外**：它不分会话，只存一份（`dsh-pin-bookmarks:rail-settings:v1`），对本机所有会话生效；改了之后，本机这个应用的其他窗口和会话也会立刻跟着变，不用刷新。
- 聊天右侧边缘「轮次导航」上那一排细横线里，被收藏的那一轮会变长（默认 26 像素）、变粗（4 像素）并换成亮色。亮色取自一组六个亮色；六个都用满后，会另算一个亮色。这些横线只对已经加载在当前会话里的轮次生效；同一轮里收藏了多条回复，也只用那一轮的一根横线。
- 「设置 → 书签」就是调这些横线的地方，也只调这些：「统一颜色」开关（默认关闭，打开时多一个取色器）、「统一长度」开关（默认打开，打开时多一个 22–28 像素、步长 1、默认 26 像素的滑杆），外加一块效果预览。收藏横线最短的那档也比普通横线长。
- 更早的收藏没有轮次号。遇到这种记录，插件会去读会话历史（被动地、一页 30 条地读，同一会话一次只走一趟，拿到需要的就不再往下翻），据此认领它属于哪一轮，横线才上得了颜色；认领不到就不画这根横线，卡片上会有一行字说明。
- 图标下面那行字只在鼠标停上去时出现，鼠标一移开就收走；但点完之后的反馈会顶掉它，并**留满 6 秒**，鼠标移不移开都一样。面板底部那行提示同样是 6 秒。
- 卡片上显示的是渲染结果，「复制」复制的是**原始 Markdown 源码**——想拿原文用它。
- 「提问」只做一件事：把引用的文字放进输入框。它不会替你发送，也不会自动补问题。
- 只有当前显示的会话才有可用的输入框；输入框不在，或者因为上一次提交还没回来而拒绝这次引用时，插件会退化成「复制到剪贴板」并提示你。
- 引用长度有上限：来自回复的整条「提问」按 2000 字截断（那条回复本来就在会话记录里），来自摘录的「提问」、自己拖选的一段、手动粘贴的内容都按 6000 字截断，超出部分以「…（后略）」标记。
- 每会话最多保留 40 条，超出后最旧的自动丢弃。
- Markdown 渲染是插件自带的轻量实现：标题、段落、列表（含一层嵌套）、引用、表格、围栏代码块、分隔线、粗体/斜体/删除线/行内代码/链接。**不渲染**数学公式、Mermaid、原始 HTML 与图片——这些会以文字形式出现；链接只放行 `http(s)` 与 `mailto`。

## 入口

- 回复下方：每条结束的回复操作行里有两个图标——「收藏到书签」（☆，只收藏、不展开）和「收藏并展开书签」（→，收藏并展开右栏）；它们的文字只在悬停时出现。
- 右侧栏标签页：「书签」（右侧栏的空状态指南页里也有它的入口卡片）。
- 会话标题右侧工具区：**书签**图标，直接展开右侧栏。
- 设置：「设置 → 书签」一节，调收藏横线的颜色、长度，并看效果预览。
